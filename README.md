# Профнастил С8

Короткое объяснение для первой смены: что это за лист, какой цвет предложить и что положить вместе с ним.

Пока Академия на паузе, обучение открыто здесь:

**https://arimberg-svg.github.io/profnastil-s8/**

Репозиторий: https://github.com/arimberg-svg/profnastil-s8

## Три позиции

- Профнастил С8 1,2×2 м, 0,45 мм, коричневый RAL 8017
- Профнастил С8 1,2×2 м, 0,45 мм, серый RAL 7024
- Профнастил С8 1,2×2 м, 0,45 мм, цинк

## Что внутри

- Что это за лист, простыми словами
- Три цвета и четыре вопроса покупателю
- Калькулятор: вписали метры забора, получили число листов
- Что положить вместе: шурупы, столбы, поперечины, заглушки, перчатки
- Три коротких вопроса перед сменой
